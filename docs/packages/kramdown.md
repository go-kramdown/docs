# kramdown

kramdown-dialect Markdown-to-HTML converter (superset of Markdown, inline attribute lists).

## Install

```bash
go get github.com/go-kramdown/kramdown
```

Requires Go 1.26.4 or newer. `CGO_ENABLED=0`.
